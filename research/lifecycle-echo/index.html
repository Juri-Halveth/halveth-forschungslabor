03 / SELBST WIEDERHOLEN

Die Quelle gehört dazu.

Das veröffentlichte Script startet vier eigene Kindprozesse mit festen synthetischen Eingaben. Ein neuer Lauf schreibt ausschließlich in einen neuen Ergebnisordner; die Webseite führt keine Prozesse auf deinem Gerät aus.

Python dokumentiert den Ausstieg als SystemExit-Ausnahme. Ob sie abgefangen wird und welcher Thread sie auslöst, verändert die Fortsetzung.
