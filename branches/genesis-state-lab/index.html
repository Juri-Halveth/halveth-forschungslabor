05 / DER RÜCKWEG

Ein Nachher.
Drei mögliche Vorher.

Bei A001 ist das Gate offen. Nur sein Signal ändert sich von 0 bis 4; alle anderen Felder bleiben fest. Durch Sättigung führen die Vorwerte 2, 3 und 4 zum selben vollständigen Nachzustand. Ein kleines Residuum hält fest, welcher Vorwert es war.

—maximale Vorbilder pro Nachzustand
—Bits als minimale feste Zusatzinformation
—geprüfte Hin- und Rückwege

Die zwei Bits rekonstruieren nur diese fünf ausdrücklich aufgezählten Vorzustände. Das Genesis-Gesamtsystem hat weitere Variablen und benötigt für einen vollständigen Rückweg einen eigenen Vertrag. Ein Content-Fingerabdruck allein ist kein Inverser.

06 / ANSCHLÜSSE

Aus einem Versuch werden neue Prüfwege.

Jede Verbindung führt zu vorhandenem Code. Die Module teilen Fragen und brauchen für eine gemeinsame Laufzeit einen geprüften Adapter.
